# LabSense Original documentation

This documentation covers the original USB-powered XIAO ESP32C3 / CCS811 / BME280 room sensor. Software **1.3.0-rc6** is a release candidate. Case revision **v3** is an enclosure revision, not LabSense v2.

The public repository contains the original product's firmware source, fabrication archive and support documentation. Second-generation hardware is a separate project and is not included here. No compatibility with a different sensor/controller/display combination is implied.
