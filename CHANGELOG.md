# Changelog

## 1.3.0-rc6 — LabSense Original

Source release candidate for XIAO ESP32C3, CCS811, BME280 and SSD1306 128 × 64.

- Individual persistent setup password and Home Assistant encryption key.
- Local Wi-Fi setup with network scanning and key copy/save before connection; Improv BLE for supported clients.
- Physical eight-second BOOT recovery that retains the pairing key.
- Encrypted OTA updates and offline setup assets.
- Fixed borderless VOC, temperature and humidity display, startup checks and four saved orientations.
- Conditioning, compensation, freshness and fault checks, configurable sustained warning thresholds and hysteresis.

Complete-product accuracy, alternative module fit and final commissioning acceptance are not established. No stable binary is provided. This is the original hardware's firmware, not firmware for a second-generation board.
