# Support and contributions

For help, include the original board/module variants, firmware version and a clear description of the problem. Check the [assembly](docs/assembly.md) and [troubleshooting](docs/operation.md) guides first. Remove Wi-Fi credentials, keys, personal addresses and identifying logs before opening a public issue. Use a private reporting route for security problems; see [SECURITY.md](SECURITY.md).

Keep contributions focused on the original hardware supported here. Include the reason for a change and how it was verified. Compile firmware changes with the pinned ESPHome version, check setup and recovery behavior, and document changed measurements or pinouts accurately. A simulation does not establish physical fit or sensor accuracy.

Preserve upstream notices and the [license applying to each material](LICENSE.md). Enclosure model files belong on MakerWorld and should not be attached to GitHub issues or pull requests.
